# my-money-check-app
生活の資金繰りどうなってるかを確認するためのWebアプリ

## 使い方

リポジトリのディレクトリで `python3 -m http.server 8000` を実行し、ブラウザーで `http://localhost:8000` を開きます。三井住友銀行の口座明細CSVや楽天カードの利用明細CSVを選択すると、それぞれの明細と合計が表示されます。CSVはUTF-8またはShift_JISに対応しています。

データはブラウザー内だけで処理され、サーバーへのアップロードや保存は行いません。ページを閉じるか再読み込みすると表示は消えます。同じ種類のCSVを選び直すと前の表示は置き換わります。

銀行は「お引出し」「お預入れ」、カードは「支払総額」をそれぞれ合計します。カードの支払総額は当月請求額と異なる場合があります。また、銀行引き落としとカード利用の二重計上を避けるため、両者は合算しません。

## テスト

Node.jsで `npm test` を実行します。依存パッケージのインストールは不要です。
