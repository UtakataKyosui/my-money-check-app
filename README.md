# my-money-check-app
生活の資金繰りどうなってるかを確認するためのWebアプリ

三井住友銀行の口座明細CSVと楽天カードの利用明細CSVを読み込み、月別・摘要別に整理・合算して表示します。
ユーザーが入稿したデータを表示するだけのアプリで、データはブラウザー内だけで処理されます。サーバーへの送信は行いません。CSVの内容は保存せず、ページを閉じるか再読み込みすると消えます（手入力した暫定支払いのみ、後述のとおりこのブラウザーに保存されます）。

## 技術スタック

React + TypeScript（Vite、Vitest、Testing Library）。開発言語は TypeScript のみです。

## 使い方

```bash
npm install
npm run dev
```

表示されたURLをブラウザーで開き、CSVを選択またはドラッグ&ドロップします。UTF-8 と Shift_JIS に対応しています。銀行とカードは見出し行から自動判定します。

### 対応するCSV

- 三井住友銀行: `年月日,お引出し,お預入れ,お取り扱い内容,残高,メモ,ラベル`
- 楽天カード: `"利用日","利用店名・商品名","利用者","支払方法","利用金額","手数料/利息","支払総額",…`（「◯月支払金額」など月によって変わる列は無視します）

### 集計の考え方

- 銀行は「お引出し」を支出、「お預入れ」を収入として扱います。
- カードは「支払総額」を支出として扱います（空の場合は 利用金額＋手数料/利息）。
- 銀行からのカード引き落としとカード利用は二重計上になり得るため、銀行の支出とカードの支出は分けて表示します。合算した支出総額は参考値です。

### 暫定支払い（手入力）

楽天カードの今月の請求額のように、CSVにまだ含まれないが金額が分かっている支払いは、「暫定支払い（手入力）」から登録できます。支払い月、内容、金額、種別（カード/銀行/その他）、確定か見込みかを入力します。

- CSVの取引とは別枠で集計し、「銀行の支出」「カードの支出」には混ぜません。概要と月別サマリーに「暫定支払い」として表示します。
- 入力した暫定支払いだけは、このブラウザーのlocalStorageに保存され、再読み込みしても残ります。CSVの内容は保存しません。
- 同じ支払いを含むCSVを読み込むと、CSVのデータが暫定値を置き換えます。一覧には「CSVで置き換え済み」と表示され、入力データは消えないので、CSVを削除すると暫定値がそのまま集計に戻ります。
  - カード: 楽天カードCSVの見出し「◯月支払金額」と利用日から支払い月を判定し、同じ支払い月のカードCSVが読み込まれると置き換えます。暫定値は削除せず、**CSVの「◯月支払金額」列の合計（その月に実際に支払う金額。分割払いなどで支払総額の合計と異なることがあります）で上書き**します。カードCSVの取引は利用月（例: 10月）の行に入りますが、暫定支払いは支払い月（例: 11月）の行に入るため、暫定値を単に外すと支払い月の行が消えてしまうからです。上書き後も、月別サマリーと月フィルタには支払い月の行が残り、確定額として「CSV確定 ○円」と表示されます。一覧には「CSVの支払額: ○円（暫定: ○円、差額 ±○円）」が表示されます。CSVの金額は保存しません（保存されるのは入力した暫定値だけです）。
  - 銀行: 暫定支払いの月の取引を含む銀行CSVが読み込まれると置き換えます。その月の取引はCSVに実在するので、暫定値は集計から外れます。
  - 種別「その他」は置き換えません。
  - 「CSVがあっても暫定値を使う」を選ぶと、その項目は置き換えません。CSVが部分的な期間しか含まない場合などに使います。
